# Rainfall assets

The current reference-night, glass-desktop and glass-mobile WebP files were generated with the built-in ImageGen tool, using the corresponding design/rainfall mockups as exact visual references. Interface text, controls and links are rendered in HTML. Desktop and mobile glass were generated separately to preserve their respective compositions. The former upstream glass atlases are no longer used.

Original design prompts: design/rainfall/IMAGEGEN-PROMPTS.md. Asset extraction requested preservation of the original scene and glass arrangement while removing UI text, symbols and controls.
